IMPORTANTE
Este repo está diseñado para convertirse en la FUENTE DE DESARROLLO Y DOCUMENTACIÓN de las tres apps sin mezclar datos de usuario.

Antes de subirlo a GitHub desde tu Mac, ejecuta:

  zsh tools/CAPTURAR_INSTALACION_ACTUAL.command
  zsh tools/VERIFY_ALL.command
  zsh tools/GENERAR_MANIFEST.command

CAPTURAR_INSTALACION_ACTUAL.command toma el código real que ya tienes instalado y verificado en:

  ~/ABRXOS_GEOMETRA_V3
  ~/Applications/ABRXOS/ABRXOS_CONTENT_BUILDER_V1
  ~/Applications/ABRXOS/ABRXOS_X_BRAND_BUILDER_V1

y actualiza apps/*/current/ sin copiar tus bibliotecas, proyectos, exports, backups ni logs.

REPO TOOLING FIX 1.0.1
====================================================================
Si CAPTURAR_INSTALACION_ACTUAL fallaba con `env: python3: No such file or directory`, usa la versión corregida de este repo y ejecuta:

  zsh tools/DEJAR_REPO_LISTO.command

Causa corregida: variable especial `path` de zsh sobrescribía PATH.

Una vez capturado y subido el snapshot real, una Mac nueva puede restaurar las tres apps con:

  zsh install/INSTALAR_ECOSISTEMA_DESDE_CERO.command
